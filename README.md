# Selective Human Review for Scalable Platinum Benchmark Curation

This repository is a fork of the official Platinum Benchmarks codebase (*Do Large Language Model Benchmarks Test Reliability?*, Vendrow et al., 2025).

> [!IMPORTANT]
> The current project implementation is **not** based on the original benchmark workflow described in [`ORIGINAL_PAPER_README.md`](ORIGINAL_PAPER_README.md).
> 
> Instead, this project implements a **Selective Human Review Auditor** and controlled stress test developed for the TAAC (Tópicos Avançados em Aprendizagem Computacional) course in the MSc in AI at U.Porto.
>
> All relevant project definitions, methodology, research questions, and evaluation criteria are documented in the [`docs/`](docs/) folder:
> - **Primary Reference:** [`docs/project_proposal.md`](docs/project_proposal.md) — Detailed implementation plan, methodology, uncertainty signals, and experimental protocols.
> - [`docs/pitch.md`](docs/pitch.md) — Executive summary and project intuition.
> - [`docs/paper.pdf`](docs/paper.pdf) — Original research paper.
> - [`docs/PracticalAssignment_TAAC.pdf`](docs/PracticalAssignment_TAAC.pdf) — Course practical assignment guidelines and evaluation checkpoints.
